バックアップ

枚数・状態はこのブラウザだけに自動保存します。別の端末へ移す前やブラウザデータを消す前に、書き出してください。

復元すると、このツールの全イベントの保存データを置き換えます。現在のデータは先に書き出してください。

使い方と注意点
  1. 「日程・メンバー」で、自分が行く日とメンバーを選びます。
  2. 日程タブを開き、参加枠の＋・−で枚数を計画します。
  3. 申込が終わったら「申込予定」をタップして「申込済み」へ。
  4. 当日は「当日」表示に切り替え、使い終わった枠にチェックします。

「―」の部は参加枠がなく、入力できません。日程やメンバーを非表示にしても、枚数は残ります。集計には非表示の入力も含めます。

注意・混雑は人数と枚数の目安です。回れるかどうかを保証するものではありません。レーンの入場締切・参加条件・変更情報は公式ページで確認してください。

撮影会は「参加券枚数」を入力します。公開案内ではCD3枚につき1回参加です。CD枚数との取り違えに注意してください。

使用済みは枠全体のチェックです。一部だけ使用した枚数の管理はVer.1では対応していません。使用済みの枠の枚数を変えると、未使用の「申込済み」に戻ります。

購入操作・ログイン・個人の申込情報のサーバー送信は行いません。端末間の自動同期はありません。別タブで更新された場合は再読込してから編集してください。
